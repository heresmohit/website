# Git & Commit Author Rules

- **Strict Author Identity**: Always commit using the user's local git configuration (`user.name` and `user.email`). Never substitute or override with any AI, assistant, or bot credentials.
- **No Co-Author Attribution**: Do not add `Co-authored-by: AI` or any bot attribution in commit messages.
- **No Personal Phone Numbers**: Keep phone numbers off public web pages and public repository documents.
