# Repository Rules & Constraints

## Git Commit Rules
- **NEVER commit with an AI or bot author**: All git commits must strictly use the user's local git configuration (`git config user.name` and `git config user.email`).
- **NO synthetic attribution**: Never add `Co-authored-by: ... [bot]`, `Antigravity`, or any AI tool name to commit messages or git metadata.
- Keep commit messages concise, factual, and human-written (e.g., `feat:`, `fix:`, `docs:`).

## Privacy & Data Rules
- **No phone numbers**: Never commit or publish personal phone numbers on any public page.
- **Authentic data only**: Zero AI-generated artwork, synthetic avatars, or fabricated case studies. All metrics and video embeds must be 100% genuine.
- **No AI jargon**: Keep all website copy grounded, direct, and conversational. Avoid words like "spearheaded", "synergistic", "force multiplier", "unforgettable", or "vital catalyst".
